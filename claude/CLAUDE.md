# Factory conventions

- Everything in repos is in English.
- Per task: spec `specs/<slug>.md`, task folder `docs/tasks/<slug>/`. Read the project's `CLAUDE.md`, `vision.md` and `styleguide.md` if present.
- Reply with a short status and file paths. Details go to files in the task folder.
- Only the coordinator edits `tasks.md` and commits.
- Out-of-scope findings (bugs, friction, ideas) go to `docs/tasks/<slug>/followups.md` (append).
