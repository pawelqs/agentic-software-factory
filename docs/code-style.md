# Code style

Factory default; a project's own `docs/code-style.md` replaces it.

- The project's formatter and linter win; run them before finishing.
- Match the surrounding code: naming, file layout, error handling, test style.
- Small functions with one job; early returns over deep nesting.
- No dead code, commented-out code or TODOs without a followup entry.
- Comments explain why, not what. English everywhere.
